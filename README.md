# Path of Exile 2 Item Inspector

![.NET](https://img.shields.io/badge/.NET-8-512BD4?logo=dotnet&logoColor=white)

A Windows desktop overlay for inspecting Path of Exile 2 item text and related trade information. The WPF application includes clipboard, parsing, configuration, and overlay components.

## Build and run

Use the .NET 8 SDK on Windows:

```bash
dotnet run --project PoE2Inspector.csproj
```

The project is an unofficial companion utility and is not affiliated with the game publisher.
